# vibe-arcade

Мод Claude Code на функциональных хуках: Блоки, Tokensurfers и Змейка в
боковой панели, пока Claude работает. Публичный репозиторий
`IulaiJedi/vibe-arcade`, он же маркетплейс плагина (`.claude-plugin/marketplace.json`). API модов ранний и меняется между версиями — истина в файле типов,
который Claude Code кладёт в `.claude-plugin/types/` при загрузке мода
(в git не хранится), и в скилле `plugin-authoring`.

## Устройство

- `hooks/register.ts` — когда открыть и закрыть панель, часы игры, поле ввода
  `Input` с `autoFocus`, которое принимает буквы без клика. Про игры знает
  только то, что написано в `hooks/arcade.ts`.
- `hooks/arcade.ts` — что мод требует от игры. Игра Claude Code не трогает:
  возвращает `Change` (перерисовать, сохранить, пересчитать часы), а рисует,
  хранит и тикает `register.ts`.
- Блоки: `game.ts` (правила), `picture.ts` (картинка), `blocks.ts` (обвязка).
- Tokensurfers: `run.ts` (правила), `runpicture.ts` (картинка: четыре пикселя
  на ячейку символами-четвертинками, два цвета на ячейку; шириной не больше 56 колонок, панель
  просит 58 — большая панель мешает переписке; сцена задана в единицах 56×52), `surfers.ts`
  (обвязка).
- Змейка: `snakegame.ts` (правила), `snakepicture.ts` (картинка), `snake.ts`
  (обвязка).
- `hooks/keys.ts` — какая клавиша какой ход в каждой игре, обе раскладки.
- `hooks/input.ts` — модуль панели: ловит стрелки после клика по картинке.

Новая игра — это объект `Arcade`, команда в `session.start` и строка
`command.run` в `register.ts`.

Состояние игр живёт в переменных модулей: переживает закрытие панели, но не
перезапуск сессии. Между сессиями в `$.store`: `isOn`, `game`, `best`,
`wallet`, `runBest`, `snakeBest`.

## Проверка

```
claude plugin validate .
claude plugin test .
```

Обе зелёные не доказывают, что панель рисуется. Дверь — настоящая сессия:
`claude --plugin-dir .` в tmux, `/blocks`, клавиши через `tmux send-keys`,
экран через `tmux capture-pane -p -e`. Клик мышью — сырой последовательностью:
`tmux send-keys -l $'\e[<0;105;10M'`, затем то же с `m` на конце. Проверять
клик по полю, клик мимо поля и русские буквы (`send-keys -l 'ф'`). Автооткрытие проверяется ходом длиннее
10 секунд в терминале от 144 колонок.

## Чего нельзя

- Чужие марки в репозитории не писать — ни в названиях, ни в текстах, ни в
  сообщениях коммитов: клоны с ними снимают с GitHub по жалобе. Игра с
  падающими фигурами называется «Блоки», команда `/blocks`.
- Версию в `plugin.json` поднимать при каждой выкладке: установленные копии
  обновляются по ней.
- QR-код в панели пробовали и сняли: меньше 23×12 клеток
  надёжного кода не бывает (сжатый вдвое по ширине OpenCV не читает).
- Строка клавиш под игрой — в одну строку (подпись до ~45 знаков): строки
  панели посчитаны, перенос сдвигает строки автора за край.
- Адреса в панели — простым текстом, не элементом `Link`: не каждый терминал
  прячет адрес под словом — иной дописывает его рядом, и строка разваливается.
- Высоту картинки считать от `e.props.scroll.bodyRows`, а не от высоты
  терминала: лишняя строка — и панель прокручивается, шапка уезжает.
- `$` не кладётся в объект и не передаётся в метод (`game.load($)` — модуль
  не загрузится). Только прямой вызов своей функции: `apply($, change)`.
- В тестах не сверять картинки после поворота фигуры: квадрат не меняется, и
  тест мигает от случайной фигуры.
- Тексты на русском, тире и «ё» не вычищать.
- В `Raster` — только символы шириной в одну ячейку.
- Управление не вешать на `hotkey` кнопок: там только латиница и цифры, в
  русской раскладке игра молчит. Буквы идут через `Input`.
- Стрелки вне поля не трогать: в панели без фокуса на поле стрелка влево
  уводит Claude Code из разговора в список агентов.
